# VSCode File Tree 插件功能与交互说明

- 类 VSCode 资源管理器的 Obsidian 侧边栏文件树：文件夹与文件混排成一棵树，展示库内全部类型的文件，支持扩展名过滤、自动定位当前文件、树内搜索、拖拽移动与行内重命名。
- 仅桌面端（需要调用系统默认程序打开 xlsx 等文件）。

# 功能

- **文件展示**
    - 展示库内所有文件（不依赖 Obsidian 的“检测所有类型文件”开关），Obsidian 不索引的点开头文件（如 `.gitignore`）除外。
    - 长文件名三种展示方式：自动换行 / 省略号截断加悬停全名 / 单行完整显示加横向滚动条。
    - 扩展名显示：全部显示 / 只隐藏 `.md` / 全部隐藏。
    - 排序：名称自然排序、修改时间、创建时间，正序或倒序；按名称排序时可选文件夹在前。
    - 紧凑文件夹、根节点、文件数量、缩进参考线、缩进宽度均可配置。
- **过滤**
    - 扩展名过滤：全部显示 / 黑名单 / 白名单，支持多段扩展名（如 `excalidraw.md`）。
    - 隐藏指定文件夹；可隐藏过滤后为空的文件夹。
- **图标**
    - 已启用 Material Icon Theme 插件时自动复用它的文件与文件夹图标，并遵循它自己的“文件图标/文件夹图标”开关；未安装时使用内置图标。
- **打开文件**
    - 单击打开或双击打开；默认打开位置可选当前标签页或新标签页，按住 Cmd/Ctrl 或中键点击使用另一种，Cmd+Alt 在右侧分屏打开。
    - Obsidian 无法打开的文件（xlsx、docx 等）用系统默认程序打开，或在访达中显示。
- **全部折叠/展开**
    - 工具栏单按钮切换：有任意文件夹展开时显示“全部折叠”，全部折叠后显示“全部展开”，点击后递归展开所有可见文件夹。
    - 搜索时只作用于搜索结果，退出搜索后恢复原来的展开状态。
- **右键菜单**
    - 新建笔记、新建文件夹、在新标签页/右侧打开、创建副本、重命名、删除。
    - 同时触发 Obsidian 的 `file-menu` 事件，书签、在访达中显示、复制路径等原生及其他插件的菜单项照常出现。
    - 其他视图（编辑器标签页等）的文件菜单中增加“在文件树中显示”。
- **多选与键盘**
    - Alt 点击切换选中，Shift 点击连续选中（与自带文件列表一致），多选后可批量删除、批量拖拽。
    - 上下键移动焦点，左右键折叠/展开或跳到上级/子项，Enter 打开，F2 重命名，Delete 或 Cmd+Backspace 删除，Esc 清除选择或退出搜索。
- **搜索**
    - 工具栏搜索按钮打开搜索框，空格分隔多个关键词（需全部命中），可配置仅文件名或完整路径、是否区分大小写。
    - 只显示命中项及其上级文件夹并自动展开，命中文字高亮；文件夹名命中时显示其下全部内容。
- **拖拽**
    - 拖到文件夹上移动（自动更新库内链接，重名自动加序号），拖到文件上则移动到该文件所在文件夹，拖到空白处移动到根目录。
    - 悬停在折叠的文件夹上约 0.75 秒自动展开。
    - 拖进编辑器插入链接；从访达拖入文件会复制到目标文件夹。
    - 可配置移动前确认，确认框中可勾选“不再询问”。

# 自动显示当前文件

- **模式**
    - 关闭 / 展开并滚动 / 展开但不滚动 / 只高亮。工具栏按钮单击在“关闭”和上次使用的模式之间切换，右键直接选择模式。
- **触发时机**
    - 只在当前文件真正变化时定位：切换标签页、分屏间切换、同一标签页打开另一个文件。
    - 焦点在编辑器与侧边栏之间切换、切回同一文件的标签页不重复定位。
    - 侧边栏视图（搜索、大纲、本视图）获得焦点，或切到空标签页、关系图谱等无文件视图时，保留上一次的高亮。
- **定位动作**
    - 展开所有上级文件夹并高亮；目标行已完整可见时不滚动，否则按“刚好可见”或“居中”滚动；横向滚动模式下同时保证名称开头可见。
- **各场景处理**
    - 在树内点击打开文件：只高亮，不展开、不滚动、不折叠其他文件夹。
    - 手动拖滚动条或滚轮浏览：不会关闭自动定位；滚动后保护时间（默认 500ms）内切换文件只高亮不滚动。
    - 之前自动展开的文件夹不会自动收起；可开启“定位时折叠无关文件夹”，或用工具栏的全部折叠/展开按钮。
    - 当前文件被扩展名规则隐藏、位于隐藏文件夹或“不自动定位的文件夹”中：不展开不滚动。
    - 当前文件被重命名或移动：高亮跟随到新位置并重新定位。
    - 视图被折叠或被其他侧边栏页签挡住：记下待定位，重新显示时补做。
    - 启动时恢复上次展开状态与滚动位置后定位一次。
- **手动定位**
    - 工具栏“定位当前文件”按钮或命令“在文件树中定位当前文件”，无论自动模式如何都会展开并滚动，并把键盘焦点放到该行。

# 面包屑导航

- 开启“跳转到文件树”后，点击编辑器顶部路径（面包屑）中的文件夹，会在本插件文件树中定位该文件夹，而不是打开自带文件列表，默认关闭。
    - 在捕获阶段拦截点击实现，关闭自带文件列表插件后同样有效；弹出窗口中的面包屑同样生效。
    - 库外文件的面包屑与右键面包屑保持原生行为。
- 跳转时展开上级文件夹，选中并聚焦目标文件夹；正在搜索时先自动退出搜索。
- 子选项“定位时展开该文件夹”默认关闭，与原生一致只选中不展开。

# 命令

- 打开文件树、在文件树中定位当前文件、切换自动显示当前文件、全部折叠/展开、全部展开、在文件树中搜索、新建笔记（文件树）、新建文件夹（文件树）。

# 开发与安装

- 安装依赖：`npm install`
- 开发监听：`npm run dev`
- 构建：`npm run build`，生成 `main.js`。
- 手动安装：将 `main.js`、`manifest.json`、`styles.css` 复制到 `<库>/.obsidian/plugins/vscode-file-tree/`，在「设置 → 第三方插件」中启用「VSCode File Tree」。
    - 更新插件后，关闭再开启插件或重启 Obsidian 使新版本生效。
